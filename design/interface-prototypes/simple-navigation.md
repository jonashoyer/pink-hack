# Navigation refinement: Home and Journal

The user finds 'Pages' unclear and requests a link to the main page instead, emphasizing maximum simplicity.

Use two primary destinations across the design:

- **Home** opens the existing symptom overview, with All and individual symptom selectors, five-day trends, today's note, and Record a note. It is the default launch destination. It does not introduce a separate dashboard.
- **Journal** opens daily notes and their associated symptom observations.

Remove Pages from primary navigation. This supersedes the three-tab phone navigation in previous mockups. The revised image keeps the latest five-symptom All chart, rather than reverting to the older attached three-symptom example. On web, use the same Home and Journal labels for the primary destinations.

The repo's context pages originally stored personal background and preferences used by the assistant. Removing their navigation does not authorize deleting those records or disabling context use. Access to personal context can be resolved separately through a small secondary settings entry if needed; it is not a third primary tab or a prerequisite for recording a note. No new settings flow is implemented in this refinement.

Only design artwork and notes change. No live app, backend, data, or deployment changes are made. The name and logo remain unselected.
