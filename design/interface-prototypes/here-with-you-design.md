# Here With You

## User-selected decisions

- Product name: **Here With You**. This supersedes the exploratory Dayleaf, Daynote, and Serein names.
- Exactly three primary destinations: **Home**, **Journal**, **Symptom**, using the user's singular label.
- Retain the calm minimal Airy Sage design direction. The final logo remains open.

Subsequent user selection: **B — A listening line** is the chosen logo. The consolidated final visual handoff is in [design/final](../final/README.md); that selection supersedes the earlier open-logo status above.

## Navigation

Home is the daily starting point: Record a note, today's saved note, and simple links to Journal and symptom trends. It no longer duplicates the full symptom chart. Journal holds editable daily notes. Symptom holds the five-day chart, All selector, individual symptom views, period selection, and symptom management. Use the same destination names on web and phone. Pages is not a primary destination; existing context records remain intact.

The phone board shows all three destinations with the corresponding active tab. The desktop mockup shows Home with three sidebar destinations. These prototypes use the existing provisional logo so the separate logo proposals are not mistaken for selected branding.

## Separate logo concepts

| Direction | Concept | Intent |
| --- | --- | --- |
| A — Shared space | Two open forms facing each other | Companionship and calm presence |
| B — A listening line | Continuous speech outline with a short voice rhythm | Listening and voice notes |
| C — Daily company | Two adjoining open pages sharing a spine | Daily writing and continuity |

Each logo is generated as its own image with the exact Here With You name and compact monochrome/reversed applications. These are bitmap concept studies. Final editable vector assets and exact small-size validation follow selection. Name availability and trademark clearance have not been researched.

## Implementation boundary

These are visual prototypes, not a native app build or live Lovable edits. Keep Jonas's existing frontend, authenticated backend, Turso storage, direct voice-writing flow, editable BlockNote notes, flexible symptom properties, and prior chart scale/data integrity rules. Prototype data and copy remain illustrative.
