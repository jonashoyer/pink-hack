# Here With You — design checkpoint

Checkpoint: 24 October 2026. The user approved the calm minimal direction, selected **B — A listening line** as the logo, and requested **Home / Journal / Symptom** navigation plus a daily overall health rating.

## Current prototypes

- [App: Home, Journal, and Symptom](final/daily-rating/app.png)
- Web: [Home](final/daily-rating/web-home.png), [Journal](final/daily-rating/web-journal.png), [Symptom](final/daily-rating/web-symptom.png)
- [Selected logo reference](final/selected-logo-reference.png)
- [Current design and daily rating notes](final/daily-rating/README.md)
- [Consolidated design handoff](final/README.md)

The daily overall health value is a self-reported 1–10 rating, with 10 meaning very good. It is separate from symptom severity, where higher means worse. All displayed data is illustrative.

These are static visual prototypes. This checkpoint does not implement or deploy the Lovable frontend or a native app. Use the existing project services and data contracts when implementing; remaining rating semantics and transcript requirements are documented in the handoff.
