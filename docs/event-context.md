## Judging

Each judge scores impact, working demo, execution, originality, and pitch clarity from 1 to 5. Impact asks whether a real affected user would use the solution. Pitch clarity covers the problem, user, solution, and what comes next.

Bonus points are +5 for using Atech and +3 for a breast cancer or cancer-related solution. The check-in answers determine bonuses. Actual Atech integration is not yet established.
